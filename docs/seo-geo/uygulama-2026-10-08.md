Bu olaylar kaydedilmiş lead/onay/ziyaret diye adlandırılmaz. Çerez açıklaması olay kapsamıyla güncellendi.

Yönetim paneli talep kaynağını ve gerçek ziyaret sonucunu ayrı kaydeder. Kaynak sunucuda website/staff; geçmiş bilinmeyen kayıtlar yeniden sınıflandırılmaz. 'Geldi/Gelmedi' yalnız tarihi gelmiş onaylı kayıt için yönetici tarafından girilir. İptal sonucu temizler. Sonuçlar Google etiketlerine gönderilmez. Eski JSON kayıtları uyumlu kalır; Supabase'in mevcut JSON veri yapısı korunur. İzole yerel dosya yolu çevre değişkeni tam yoluyla çalışır; testler gerçek müşteri deposuna yazmaz.

EN/RU/AR/KO/JA ortak rehberleri açık İngilizce form geçişi ve teyit koşulu içerir. Ortak 1978 footer anlatısı aile hikâyesi ile güncel Beyoğlu adresini ayırır. Japonca/Korece ürün ve şema metinlerinden menüyle desteklenmeyen manda sütü/iki ev yapımı reçel ifadeleri kaldırıldı; temel kaymak kültürü açıklaması korundu. Değişmiş rehberlerin görünür/şema/sitemap tarihleri güncellendi. Ana dili editör kontrolü ve işletme tedarik teyidi ayrıca gerekir.

Footer görseli %97,2 küçüldü; hero/menü banner kalite yükü ve aynı fotoğrafın kalite varyantları azaltıldı. LCP medyanı anlamlı biçimde düşmedi; hedefi tamamlanmış saymıyoruz. Ayrıntı [performans kaydı](performans-2026-10-08.md).

## Doğrulama

- `npm run build`: Next üretim build ve TypeScript başarılı.
- `npm run lint`: başarılı.
- `npm run test:seo`: 30 canonical sayfa, 48 eski URL, hreflang, indeksleme/özel sayfa, sitemap, yapılandırılmış veri ve 404 kontrolleri.
- `npm run test:analytics`: UTM'nin taze oturumdaki yapılandırma/page_view eşliği, gezinme olayları, çift event/PII ve özel rota kontrolü.
- `npm run test:menu`: 142 ürün/18 kategori SSR, düzenlenebilir fiyat/açıklama/şema, karşılaştırma/rehber anında yenileme; gerçek API ile yönetici yetkisi, sahte kaynak/onay engeli, ziyaret tarih/durum doğrulaması.
- `npm run test:reservations`: İstanbul saat dilimi, özel ICS, kalıcı depolama hatası ve iptal edilmiş ziyaret sonucu kontrolü.
- Tarayıcı: 390 px mobil ve 1280 px masaüstü karşılaştırma taşması yok; ürün hash'i, ayrıntı penceresi ve English request geçişi kontrol edildi. İşlem testleri yalnız izole fixture üzerinde; sahte production lead yok.
